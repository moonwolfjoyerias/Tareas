# Tareas MW

App de tareas por voz. Tocas el lobo, dictas tu pendiente y Gemini lo convierte en una tarea con título, descripción, pasos, fecha y prioridad.

- Abrir: https://moonwolfjoyerias.github.io/Tareas/
- Datos: Firebase (proyecto `tareas-mw`, plan Spark gratuito). Cada usuaria solo ve sus propias tareas.
- IA: Gemini con la clave gratuita de Google AI Studio, guardada en la cuenta privada de Firebase (no en este código).
